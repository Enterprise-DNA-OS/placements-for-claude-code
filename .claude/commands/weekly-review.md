---
description: The Monday review for the placement coordinator, written from attention, capacity and hours into drafts/.
---

1. Run `npm run placements -- attention --json`, `npm run placements -- capacity --json`, `npm run placements -- hours --short --json` and `npm run placements -- compliance`.
2. Write `drafts/weekly-review-<YYYY-MM-DD>.md` with four short sections: **Stop before they start** (checks, agreements, supervisors for anyone starting in the next 30 days), **Students waiting** (unplaced students and the open places that could take them), **Hours** (final-year students short, and hours waiting for sign-off), **Follow up** (late assessments, open incidents, hosts gone quiet).
3. Each line names the student or host, what is wrong and the one action. No more than a page.
4. Show the operator the file path and the three most urgent lines. Never send it.
